# Pi Extension Design

Use this fixture skill for work on Pi extension packages.

## Workflow

1. Read the relevant Pi documentation for extensions and packages.
2. Decide whether the behavior belongs in a tool, command, event hook, or package resource.
3. Keep extension behavior minimal, reversible, and documented.
4. Validate with a focused command or a small fixture.

## Done

The extension design names the API surfaces used, explains limitations, and includes a focused validation path.
